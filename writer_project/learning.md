## 2026-07-11 세션 — 문서 구조 개편 작업 중 학습

### 1. 연결자 (명령을 잇는 법)

**`&&` (그리고)**
- 목적: 앞 명령이 성공했을 때만 다음을 실행 (실패하면 거기서 멈춤 = 안전벨트).
- 문법 핵심: `A && B` → A가 성공(exit 0)해야 B 실행. `A && B && C`로 사슬 가능.
- 적용·확장: `mv x y && echo "moved"` (옮겨졌을 때만 "moved"). commit이 성공해야 push하는 식으로 순서 보장.

**`||` (아니면)**
- 목적: 앞 명령이 실패했을 때만 다음을 실행 (플랜 B).
- 문법 핵심: `A || B` → A가 실패해야 B 실행. `A && B || C` = "되면 B, 안 되면 C" 분기.
- 적용·확장: `git ls-files x || echo "UNTRACKED"` (관리 안 하면 안내문). 실패 시 대체 메시지 출력에 단골.

**`|` (파이프, 컨베이어)**
- 목적: 앞 명령의 출력을 다음 명령의 입력(재료)으로 넘김.
- 문법 핵심: `A | B` → A가 뱉은 결과를 B가 받아 가공. (&&는 순서, |는 데이터 전달 — 다름)
- 적용·확장: `git ls-files | wc -l` (목록을 세기로), `... | grep '.py'` (목록을 거르기로). 조회+가공 조합에 필수.

### 2. 리다이렉션 (결과를 파일로)

**`>` (덮어쓰기)**
- 목적: 명령 결과를 화면 말고 파일로 쏟아 넣음 (기존 내용은 날림).
- 문법 핵심: `명령 > 파일` → 파일이 있으면 통째 덮어씀. 새 파일이면 생성.
- 적용·확장: `sed -n '1,409p' 원본 > 새파일` (일부만 잘라 새 파일로). 주의: 실수로 기존 파일 지목하면 원본 소실.

**`>>` (이어붙이기)**
- 목적: 결과를 파일 끝에 추가 (기존 내용 보존).
- 문법 핵심: `명령 >> 파일` → 덮지 않고 뒤에 append.
- 적용·확장: `> 로 제목 쓰고 >> 로 본문 이어붙이기`. `>`와 헷갈리면 앞 내용이 날아가니 구분 필수.

**`<< 'EOF' … EOF` (heredoc, 받아쓰기 상자)**
- 목적: 여러 줄을 한 번에 파일로 써넣기.
- 문법 핵심: `cat > 파일 << 'EOF'` ~ `EOF` 사이 내용을 통째 입력으로. 따옴표친 'EOF'는 특수문자 원문 보존.
- 적용·확장: 설정 파일·subagent .md를 명령 한 방에 생성. EOF는 임의 이름표(관습).

### 3. 파일 조회

**`cat`**
- 목적: 파일 내용을 화면에 통째로 출력.
- 문법 핵심: `cat 파일`. `>`와 만나면 방향이 반대(파일에 쓰기)가 됨.
- 적용·확장: 짧은 파일 전체 확인. 긴 파일은 head/sed로 대체.

**`head -N` / `tail -N`**
- 목적: 파일 위/아래 N줄만 미리보기.
- 문법 핵심: `head -5 파일`(위 5줄), `tail -3 파일`(아래 3줄).
- 적용·확장: 파일 성격·끝맺음 빠른 확인. 로그 꼬리 보기에 tail 단골.

**`sed -n 'A,Bp' 파일`**
- 목적: 파일의 임의 구간(A~B줄)만 뽑기.
- 문법 핵심: `-n`=지정 줄만 조용히, `'400,420p'`=400~420줄 print. 숫자만 바꾸면 아무 구간.
- 적용·확장: 파일 중간 확인(경계선 찾기), `> 파일`과 합쳐 구간 추출·분할. head/tail이 못 하는 한가운데용.

**`ls -1` / `ls -lt`**
- 목적: 폴더 목록 보기.
- 문법 핵심: `-1`=한 줄에 하나씩, `-lt`=상세+수정시각 최신순.
- 적용·확장: `ls -1 ~/.claude/agents/`(파일 존재 확인), `ls -lt paper_*.md | head`(최신 파일 찾기).

**`find 경로 -name '패턴'`**
- 목적: 하위 폴더까지 파고들어 조건 맞는 파일 찾기.
- 문법 핵심: `find scripts -name '*.md'` → scripts 및 모든 하위에서 .md 전부. (ls는 한 층, find는 땅속까지)
- 적용·확장: `find ... | wc -l`(개수), `| sort`(정렬). 여러 겹 폴더 전수 조사에.

**`wc -l`**
- 목적: 줄 수 세기.
- 문법 핵심: `wc -l 파일`(줄 수), 여러 파일 주면 각각+total.
- 적용·확장: 분량 비교, `| wc -l`로 목록 개수 세기. 분할 검산(원본=조각합)에 유용.

**`grep -nE '패턴'`**
- 목적: 조건에 맞는 줄만 걸러내기(체).
- 문법 핵심: `-E`=정규식 켬, `-n`=라인번호, `^`=줄 시작, `$`=줄 끝, `#{1,3}`=# 1~3개.
- 적용·확장: `grep -nE '^#{1,3} ' 파일`(markdown 목차 추출), `| grep '\.py$'`(.py만 필터). 긴 문서 구조 파악·범위 검문에.

### 4. 경로 기호

**`~` / `.` / `../`**
- 목적: 위치를 가리키는 기준점.
- 문법 핵심: `~`=홈(/Users/ohsungsu, 현재위치 무관), `.`=지금 폴더, `../`=한 단계 위.
- 적용·확장: `~/.claude/agents/`(어디서 쳐도 홈), `../.venv_vertex`(하위폴더에서 루트 venv 지목). 상대경로는 "그 파일이 선 자리 기준", 절대경로·~는 고정.

### 5. git 흐름 (커밋 5단계)

**`git status` / `git diff --cached --stat`**
- 목적: 현재 상태·무대에 올린 변경 확인.
- 문법 핵심: `status`=브랜치+안올라간 커밋+변경파일, `diff --cached`=staged된 것만, `--stat`=파일별 줄 변화.
- 적용·확장: 커밋 전 범위 검문. `--name-only`/`--name-status`로 형식 조절.

**`git add`**
- 목적: 커밋 무대(staging)에 파일 올리기.
- 문법 핵심: `git add 파일들` → 여기 올린 것만 다음 커밋에 포함. (아직 커밋 아님)
- 적용·확장: 올린 것만 커밋되므로 "무엇을 add하냐"가 곧 커밋 범위. 되돌리기=`git restore --staged`.

**`git mv`**
- 목적: 파일 이동/이름변경을 git에 이력 보존하며 기록.
- 문법 핵심: `git mv 원래 새위치` → 일반 mv와 달리 "이사"로 인식(이력 따라감).
- 적용·확장: 아카이브 파일 옮길 때 과거 커밋 이력 유지. `git rm`+`git add`로도 rename 자동 감지될 수 있음.

**`git commit -m`**
- 목적: 무대에 올린 것을 커밋으로 확정(로컬 기록).
- 문법 핵심: `-m "메시지"`. 1줄 제목(docs:/fix:/feat: 꼬리표) + 빈줄 + 본문 관습.
- 적용·확장: 되돌리기=`git reset --soft HEAD~1`(커밋만 취소, 파일 보존). ⚠️`--hard`는 파일까지 날림.

**`git push`**
- 목적: 로컬 커밋을 원격(GitHub)에 업로드.
- 문법 핵심: `git push`. commit까지는 로컬만, push해야 원격 반영.
- 적용·확장: 올리기 전 `git log origin/main..HEAD --oneline`으로 "뭘 올리는지" 미리 확인. "커밋했는데 GitHub에 없음"의 답은 대개 push 누락.

### 6. 기타

**`mkdir -p`**
- 목적: 폴더 생성(중간 경로까지 한 번에).
- 문법 핵심: `mkdir -p a/b/c` → a, b, c 없으면 다 만듦. 이미 있어도 에러 안 남.
- 적용·확장: `mkdir -p ~/.claude/agents`(중첩 폴더 한 방). `-p` 없으면 부모 없을 때 실패.

**`cp` + `2>/dev/null`**
- 목적: 복사 / 에러 메시지 숨기기.
- 문법 핵심: `cp 원본 사본`(복사), `2>/dev/null`=2번(에러) 출구를 허공으로 버림.
- 적용·확장: `cp x /tmp/x.bak`(백업), `... 2>/dev/null || echo none`(실패해도 조용히 대체). 위험 작업 전 백업 습관.

## 2026-07-12 세션 — faithfulness rank + 인용 다양성 트랙 (파이썬 대량 등장)

> 이번 세션은 파이썬이 주. 아래는 **파이썬 파트 신설** + bash는 새로 나온 것만 추가.
> 큰 흐름: JSON 데이터를 읽어 → 정규식으로 훑고 → 조건별로 분류·집계 → 표로 출력.

═══════════════════════════════════════════════
### 파이썬 — 정규식 (re)
═══════════════════════════════════════════════

**`re.compile(패턴)` — 패턴 미리 만들기**
- 목적: 같은 패턴을 여러 번 쓸 때 미리 컴파일해 재사용.
- 문법 핵심: `_MARK=re.compile(r'\[\[.*?\]\]')` → 이후 `_MARK.findall(s)` 식으로.
- 적용·확장: 반복문 안에서 매번 패턴 해석하는 낭비 제거.

**`re.search` / `findall` / `finditer` / `fullmatch` — 찾는 4형제**
- 목적: search=첫 하나 / findall=전부(문자열) / finditer=전부(위치까지) / fullmatch=전체 일치.
- 문법 핵심: `re.search(p,s).group(1)`(캡처 꺼냄) / `re.findall(p,s)`(리스트) / `re.finditer` 후 `m.start()` `m.group(0)` / `re.fullmatch`는 부분매칭 불가.
- 적용·확장: 위치 필요하면 finditer(섹션 판정), 모양 분류는 fullmatch. ⚠️ search 못 찾으면 None → `if m:` 방어.

**`re.sub(p, 대체, s)` — 치환 (특히 "정규화")**
- 목적: 맞는 부분을 다른 걸로 바꾸기. 삭제하려면 대체를 ""로.
- 문법 핵심: `re.sub(r'\d+','#',c)` = 숫자를 전부 #으로 → 모양만 남김. `re.sub(r'[^a-z0-9]+',' ',t)` = 영숫자 외 제거.
- 적용·확장: ⭐"정규화" = 관심 없는 차이(숫자값·특수문자)를 지워 본질(모양·제목)만 남기기. 같은 것 판정의 핵심.

**`re.split(p, s)` — 패턴으로 쪼개기**
- 목적: 구분자 패턴 기준으로 문자열 분리 (문장 나누기 등).
- 문법 핵심: `re.split(r'(?<=[.!?])\s+(?=[A-Z])', line)` = "마침표 뒤 + 대문자 앞"에서 자름.
- 적용·확장: lookaround로 자르는 기준점 자체는 안 먹고 위치만 봄(마침표 안 사라짐).

**패턴 문법 모음**
- 목적: 정규식 재료들.
- 문법 핵심: `r'...'` raw(백슬래시 그대로) / `\d`숫자 `\s`공백 `\d+`하나이상 `\d{8}`정확히8개 / `[^a-z]`부정(대괄호 앞 ^) / `\[`이스케이프 / `(...)`캡처 `(?:...)`묶기만 / `(?m)`멀티라인 / `\b`단어경계.
- 적용·확장: lookaround = `(?<=x)`앞조건 `(?=x)`뒤조건 `(?<!x)`앞부정 `(?!x)`뒤부정. 예 `(?<!\[)\[\d+\](?!\])` = 진짜 단독 [N].

**⭐ `.*` vs `.*?` — 탐욕/비탐욕 (이번 최대 함정)**
- 목적: 여러 개 중 하나씩 잡기 vs 통째로 삼키기.
- 문법 핵심: `.*` = 최대한 많이(마지막까지 삼킴) / `.*?` = 최소한만(가장 가까운 데서 멈춤).
- 적용·확장: `\[\[.*?\]\]`로 `[[2]]`,`[[1], [2]]`를 각각. `?` 빼면 한 줄에 마커 2개일 때 사이 문장까지 다 먹음.

**⭐ 2단 계수 — 다중묶음 처리 (이번 핵심 교훈)**
- 목적: `[[2], [9]]` 같은 묶음 인용을 참조번호 단위로 세기.
- 문법 핵심: 바깥 덩어리 먼저(`\[\[.*?\]\]`) → 안에서 숫자(`\d+`). `for ch in CHUNK.findall(s): for n in INNER.findall(ch): ...`
- 적용·확장: 단독만 잡는 `\[\[(\d+)\]\]`는 묶음을 통째 누락. 이 착시가 세 겹(인용소실·표본병목·misaligned0)을 만들었음.

═══════════════════════════════════════════════
### 파이썬 — 문자열 / 슬라이스
═══════════════════════════════════════════════

**`.find` / `.lower` / `.strip` / `.split` / `.join` / `in`**
- 목적: 문자열 기본 가공.
- 문법 핵심: `s.find("x")`=첫 위치(없으면 -1) / `.strip()`=앞뒤공백제거 / `s.split(':')[1]`=쪼개 조각 / `" / ".join(리스트)`=이어붙이기 / `"x" in s`=포함검사.
- 적용·확장: find는 "존재+위치 동시에". join은 리스트→표 문자열. `"─"*70`=문자열 곱하기(구분선).

**슬라이스 — 음수 인덱스 포함**
- 목적: 문자열/리스트 일부 잘라내기.
- 문법 핵심: `s[:200]`앞200 / `s[i:]`i부터끝 / `s[-70:]`끝에서70(음수=뒤에서) / `ch[0]`첫항목.
- 적용·확장: abstract 잘림 확인은 꼬리를 봐야 하니 `a[-70:]`. `t[:i]`앞부분/`t[i:]`뒷부분 짝.

═══════════════════════════════════════════════
### 파이썬 — 컬렉션 (list / set / dict / Counter / defaultdict)
═══════════════════════════════════════════════

**list 조작**
- 목적: 리스트 추가·제거.
- 문법 핵심: `.append(x)`하나추가 / `lst += [a,b]`통째이어붙이기(=extend) / `.pop(0)`앞꺼내며제거 / `.pop()`뒤.
- 적용·확장: 덩어리마다 숫자 여러 개 나오면 append 아닌 `+=`.

**`set` — 중복 제거·집합 연산**
- 목적: 중복 없는 모음. "몇 종류?"에 답.
- 문법 핵심: `len(set(x))`=중복빼고개수(관용구) / `A & B`교집합 / `A - B`차집합.
- 적용·확장: 고유 논문 수 세기, 문장 중복 제거(이미 본 것 기억). 헤딩↔chunk섹션 이름 매칭 대조.

**`dict.get` — 안전하게 꺼내기**
- 목적: 없는 키 접근해도 에러 안 나게.
- 문법 핵심: `d.get(k)`없으면None / `d.get(k, 기본값)`없으면기본값 / `k in d`키존재확인.
- 적용·확장: `d["x"]`는 키 없으면 에러. 구조 확신 없을 때 방어적으로 `.get`.

**`Counter` / `defaultdict` (from collections)**
- 목적: 자동 집계·자동 초기화 딕셔너리.
- 문법 핵심: `Counter(리스트)`개수자동 → `.most_common()`빈도순 `.items()`쌍들 / `defaultdict(list)`없는키를빈리스트 / `defaultdict(lambda:{...})`복잡한기본값.
- 적용·확장: 섹션별 인용 집계, 신원별 정보 누적. lambda로 감싸는 이유=값이 아니라 "값 만드는 함수"를 받으므로.

### 파이썬 — 컴프리헨션
═══════════════════════════════════════════════

**리스트 / 딕셔너리 / 제너레이터 / next**
- 목적: 반복을 한 줄로. 새 리스트/딕셔너리 만들기.
- 문법 핵심: `[f(x) for x in xs]` / `[x for x in xs if 조건]`(필터) / `{k:v for k,v in ps}`(딕셔너리) / `sum(1 for x in xs if 조건)`(개수세기) / `next(x for x in xs if 조건)`(첫 하나만).
- 적용·확장: 대괄호 없는 `Counter(f(x) for x in xs)`=제너레이터(리스트 안 만들고 흘림). next는 다 안 만들고 멈춤(효율).

### 파이썬 — 함수 / 흐름 제어
═══════════════════════════════════════════════

**`def` / 중첩함수 / `lambda`**
- 목적: 반복 작업 묶기 / 이름 없는 즉석 함수.
- 문법 핵심: `def f(a,b): ... return x` / 함수 안 함수(바깥 변수 참조) / `lambda: X`=`def f():return X` 한줄판.
- 적용·확장: 파일 읽기+자르기를 `bodyof(f)`로 묶어 재사용. lambda는 정렬 key·defaultdict 기본값에.

**정렬 key / 조건식 / 흐름**
- 목적: 정렬 기준 지정, 조건 분기, 반복 제어.
- 문법 핵심: `sorted(xs, key=lambda x:-x[1])`(마이너스=내림차순) / `A if 조건 else B`(삼항, f-string 안에서도) / `1<=n<=89`(연쇄비교) / `continue`건너뛰기 `break`탈출 / `if 리스트:`빈것=거짓.
- 적용·확장: `key=lambda`로 "이 기준으로 줄세워라". 내림차순은 `-값` 또는 `reverse=True`.

**`enumerate` / ±1 인덱스 변환**
- 목적: 번호+항목 동시 순회.
- 문법 핵심: `for i,c in enumerate(xs):` / `enumerate(xs, 시작번호)`.
- 적용·확장: ⭐enumerate는 0부터, 인용마커 [[N]]은 1부터 → 꺼낼 때 `chunks[n-1]`, 번호만들 때 `i+1`. 이 코드베이스 전체에 깔림.

### 파이썬 — f-string / 파일 / numpy
═══════════════════════════════════════════════

**f-string 포맷**
- 목적: 값 삽입 + 정렬·자릿수 맞춰 표 찍기.
- 문법 핵심: `f"{x!r}"`repr(따옴표·숨은문자) / `{x:10}`10칸왼쪽 `{x:>7}`오른쪽 `{x:>+7}`부호표시 / `{x:.0f}`소수없이 `{x:.4f}`4자리 / 안쪽 딕셔너리는 `f"{p['k']}"`(따옴표 구분).
- 적용·확장: 콘솔 표 정렬의 기본. 증감 보여줄 때 `:>+7`.

**파일 / JSON / glob**
- 목적: 파일 읽기, JSON 파싱, 이름패턴 파일 수집.
- 문법 핵심: `json.load(open(f,encoding="utf-8"))`=딕셔너리로(encoding은 한글깨짐방지) / `open(f).read()`=문자열하나 / `glob.glob("paper_*.md")`=패턴맞는파일리스트.
- 적용·확장: glob은 bash find의 파이썬판. 파일명 정렬=시간순(YYYYMMDD 자릿수 고정 시).

**numpy — 임베딩 유사도**
- 목적: 문장↔초록 유사도를 한 번에 계산.
- 문법 핵심: `emat @ q`=행렬곱, (N×1024)@(1024)=N개 유사도 동시 / `np.dot(v1,v2)`=내적=코사인유사도 하나.
- 적용·확장: ⚠️`emat @ q`를 컴프리헨션 안에 넣으면 N번 반복→밖으로 빼 `sims=emat @ q` 한 번만. 절대값보다 등수(rank)가 도메인포화 상쇄.

### bash — 이번 세션 신규 (기존 항목 제외)
═══════════════════════════════════════════════

**`-o` (grep 맞은 부분만) / `-v` (제외)**
- 목적: 줄 전체 말고 맞은 부분만 / 조건 뒤집어 제외.
- 문법 핵심: `grep -oE '\[\[[0-9]+\]\]'`=마커만 한 줄씩 / `grep -v test`=test 든 줄 빼기.
- 적용·확장: `grep -o ... | wc -l`=매치 개수 세기. `| grep -v`로 노이즈(테스트 등) 거르기.

**`find -type` / `-iname` / `\( -o \)`**
- 목적: 폴더냐 파일이냐 / 이름패턴(대소문자무시) / or 조건 묶기.
- 문법 핵심: `-type d`폴더 `-type f`파일 / `-iname "*chroma*"`(-i=대소문자무시) / `\( -iname A -o -iname B \)`(-o=or, 괄호 이스케이프).
- 적용·확장: grep은 "파일 안 내용", find는 "파일·폴더 존재 자체". 짝으로 기억.

**`awk '{print $1}'` / `tr -d` / `printf '%s'`**
- 목적: 열 뽑기 / 글자 삭제 / 안전 출력.
- 문법 핵심: `awk '{print $1}'`=공백기준 첫열($0전체 $2둘째) / `tr -d ' '`=공백삭제 / `printf '%s' "$x"`=echo보다 특수문자 안전.
- 적용·확장: `wc -l | awk '{print $1}'`=줄수 숫자만(파일명·공백 제거). tr도 같은 목적 가능.

**`$(...)` 명령 치환 / 변수 / `python -c`, heredoc**
- 목적: 명령 결과를 그 자리에 끼우기 / 짧은·긴 파이썬 실행.
- 문법 핵심: `cd "$(git rev-parse --show-toplevel)/writer_project"` / `NEW="파일"`(=양옆 공백 없이) 사용 `"$NEW"` / `python -c "코드"`한줄 / `python - <<'PY' ... PY`여러줄.
- 적용·확장: repo 꼭대기 기준 이동으로 경로 실수 방지. bash 변수를 파이썬 문자열에 끼우기 `'$f'`(큰따옴표 안 치환). ⚠️`§`경로·glob은 따옴표 필수.

### 문법 아닌 것 — 데이터 다루는 사고방식 (이번 세션 진짜 교훈)
═══════════════════════════════════════════════

- **정규화(normalize)**: 관심 없는 차이를 지워 본질만 남기기. 숫자→#(모양만), 제목 소문자+특수문자제거(같은 논문 판정).
- **교차검증**: 한 지표 믿지 말고 여러 각도로 재서 일치 확인. abstract 잘림 = 길이뭉침 + 상위길이천장 + 문장부호없이끝남 + 육안, 4각도.
- **"데이터가 있다" ≠ "모델이 본다"**: full abstract라도 e5는 앞 ~512토큰만 봄. 키워드가 그 범위 안에 있냐가 관건.
- **싼 측정 먼저**: 비싼 탐지기(LLM) 짓기 전에 값싼 계산으로 문제 실재부터 확인. 이번 세션 착시 5겹을 매번 이게 걸러냄.

## 2. 일동제약 아로나민 — 60년 광고 자산의 누적

### 2.1 모델 변천사 (1960년대 ~ 2026)

| 연도 | 모델 | 슬로건/콘셉트 |
|---|---|---|
| 1960년대 | **김기수** (당시 권투 챔피언) | "체력은 국력이다" |
| 1970년대 초 | 일반인 (전문직 시리즈) — 철도기관사·비행기 파일럿·등대지기 등 | "의지의 한국인" 시리즈 |
| 1980년대 | 남궁원 (영화배우) → 길용우 (탤런트) | — |
| 1990년대 | 심양홍 (탤런트) → 허영호 (산악인) | — |
| 2010년대~ | (다수) | **"먹은 날과 안 먹은 날의 차이"** 슬로건 정착 |
| 2024.02~ | **손석구** | "먹은 날과 안 먹은 날의 차이, 경험해보세요" — 직장인 편 / 사무실 편 |
| 2025.02~ | **류승룡** | "약이니까 다르지" / "아로나민은 약국에 있습니다" — 출퇴근 지하철 → 약국역 콘셉트 |
| 2025.08~ | 류승룡 (후속편) | "내 몸을 1등으로 생각한다면, 비타민 판매 1위 아로나민 골드" — IQVIA 1위 강조 |
| 2026.03~ | 류승룡 (상반기) | **"대한민국 피로엔 아로나민 골드가 간다!"** — 직무 현장 찾아가는 콘셉트 |

### 2.2 핵심 메시지 자산 분석

#### A. "먹은 날과 안 먹은 날의 차이" — 10년+ 캐치프레이즈

- 비교 광고 규제 회피 + 사용자 자체 비교 유도 (1인칭 시점)
- "어떤 효과가 있다" 직접 클레임 회피 — 사전심의 안전
- 유사 표현 무한 변주 가능 (직장인편/사무실편/지하철편 등)

#### B. "약이니까 다르지 / 아로나민은 약국에 있습니다" — 의약품 정체성 강조 (2025~)

- **건기식 비타민(오쏘몰 이뮨 등)에 대한 카테고리 방어 메시지**
- 시장 잠식 위협(시장규모 자료 1.3 참조)에 대한 직접 대응
- 약국 채널 회복세(시장규모 자료 1.2 참조)와 부합

#### C. "비타민 판매 1위" — IQVIA 데이터 기반 권위 클레임 (2024 데이터, 2025 활용)

- 매체에 데이터 출처(IQVIA 2024) 명시 — 사전심의 통과 안전성 확보
- 카테고리 1위 기반 권위 마케팅

#### D. 푸르설티아민 시각 표현 — "뇌세포막 통과" 시각화

- 인체 그래픽 + 머리에서 온몸으로 에너지 퍼지는 처리
- 활성형 B1 차별화를 시각 자산으로 누적

### 2.3 채널·접점 전략

- TV CF 메인, 약국 POP 보조, 디지털 후속
- "약국역" 콘셉트 광고 — 약국 채널 회복 트렌드와 연동

## 3. 대웅제약 임팩타민 — TV 광고 늦은 진입의 대가

### 3.1 광고 시작점

- 2007년 출시 → **2019년 7월 첫 TV CF** (12년 후)
- 모델: **염정아·오나라** ('SKY캐슬' 출연진)
- 콘셉트: 가족 건강을 꼼꼼하게 챙기는 엄마 (드라마 캐릭터 차용)
- 카피: **"비타민B의 더블 임팩트, 임팩타민"**

### 3.2 핵심 메시지 자산 분석

#### A. "더블 임팩트" — 함량·성분 강조

- 비타민B 8종 함유 + 피로회복 + 에너지 생성 시너지 메시지
- 고함량·다성분 트렌드와 부합 (출시 시점에는 차별화)
- **2024년 시점 평가**: 모든 경쟁사가 고함량 따라오면서 차별화 소실. 메시지 피크아웃.

#### B. 모델 일관성 약함

- 2019 염정아·오나라 이후 메인 모델 누적이 빈약 (공개 보도 기준)
- 아로나민(손석구→류승룡)과 벤포벨(이성민 3년+)이 모델·메시지를 누적시키는 동안 임팩타민은 **상대적으로 정체**

#### C. 현재 매체 메시지 (2024~)

- 라인업별 분산 (프리미엄 / 케어 / 파워A+ / 시그니처)
- 통합 슬로건 부재 — 라인업별 메시지가 따로 노는 인상

### 3.3 광고기획 시사점 — 임팩타민의 약한 고리

- **공격 포인트로 적합**: 슬로건 일관성·모델 자산 면에서 가장 취약
- 단 사전심의 규제(자료 2.1)상 비교 광고는 불가 → **"통합 슬로건 자산"으로 우회 차별화**

## 4. 종근당 벤포벨 — 출시 5년 후 광고 폭발 + 무결성 관리

### 4.1 모델·캠페인 흐름

| 시점 | 모델 | 콘셉트/카피 |
|---|---|---|
| 2016~2020 | 광고 미공개 (브랜드 빌딩 단계) | — |
| **2021.03** | **이성민 발탁** (1년차) | "퇴근 후 우동편" — 일상 직장인 피로 |
| 2022 | 이성민 (2년차) | "차원이 다른 피로엔, 오래 가는 비타민" |
| **2023.02** | 이성민 (3년차) — **벤포벨S 런칭** | **"어른들의 피로엔 어른들의 비타민"** — 두 편 ('애들은 모르는' / '어른들만 아는') |
| 2024 | 이성민 지속 | 디지털·온라인 채널 확장 |

### 4.2 핵심 메시지 자산 분석

#### A. "어른들의 비타민" — 처방 사양과 슬로건의 무결성

- 만 19세 이상 성인 한정 (UDCA 60mg 표준제조기준상 용법) → **슬로건이 처방 사양과 일치**
- "애들은 모르는" / "어른들만 아는" 변주 — 어른 정체성을 메시지 자산으로 누적
- 사전심의 통과 안전성 — "어른"은 효능 클레임이 아닌 타겟 정의이므로 규제 영향 없음

#### B. 이성민 3년+ 일관 모델

- "신뢰감"·"진중함"·"공감" 톤 — 어른 정체성과 부합
- 아로나민(손석구·류승룡)과 톤 차별화 — 아로나민은 유쾌·해결사, 벤포벨은 공감·동행

#### C. "차원이 다른 피로엔, 오래 가는 비타민" (2022) → "어른들의 피로엔" (2023~)

- 슬로건 진화 시 메시지 골격 유지 (피로 + 차별화)
- 벤포벨S 런칭에 맞춰 타겟 명확화 ("성인 한정")

#### D. 약사 마케팅 병행

- TV CF + 전문 매체 (약사공론 등) + 약사 대상 학술 마케팅 ("학술 복약지도 툴" 제공)
- 종근당 공식 입장: **"미충족 수요(Unmet Needs) 파악 → 소비자 친화적 마케팅"**
- 약사 1,000명+ 설문(약사공론 이벤트)을 통해 약사 인식 자체를 자산화

### 4.3 채널·접점 전략

- TV CF 메인 + 디지털 후속
- 약사 매체 (약사공론 등)에 별도 콘텐츠 (학술 복약지도 툴, 이벤트, 인터뷰)
- 약국 POP — 처방 사양(UDCA 60mg, 메코발라민) 디테일은 약국 접점에 한정

### 4.4 광고기획 시사점 — 벤포벨의 자산과 위협

#### 자산

- 슬로건·모델·처방 사양 **3중 무결성** → 메시지 신뢰도 ↑
- 약사 인식 자산 (UDCA+타우린+메티오닌+오로트산 조합 권매 포인트 1위 56%)
- 시장 역성장기에 +48% 성장한 모멘텀

#### 위협

- 라인업 폭이 좁음 (3종) — 약국 추천 다양성에서 불리
- 인지도는 아로나민 대비 절대 격차 (60년 vs 10년)
- "어른" 슬로건이 너무 굳어지면 **35세 이하 신규 진입 어려움** — 디지털 채널 별도 메시지 필요

## 5. 3강 메시지 포지셔닝 맵

### 5.1 톤·정서 축

```
유쾌·해결사 (아로나민 류승룡)  ←→  진중·동행 (벤포벨 이성민)
                              가족·꼼꼼 (임팩타민 염정아)
```

### 5.2 메시지 핵심 축

| 메시지 차원 | 아로나민 | 임팩타민 | 벤포벨 |
|---|---|---|---|
| **타겟** | "대한민국 피로 (전 국민)" | "가족 건강" | "어른" |
| **차별점 표현** | "약이니까 다르지" (의약품 정체성) | "더블 임팩트" (함량) | "어른들의 비타민" (성분 통합) |
| **사용 신호** | "약국에서 만나요" | "꾸준히 챙기세요" | "어른들의 피로엔" |
| **권위 자산** | "비타민 판매 1위 (IQVIA 2024)" | "활성비타민 벤포티아민" | "메코발라민·UDCA 60mg 국내 최초" |

### 5.3 빈 공간 (벤포벨이 노릴 영역)

기존 3강 메시지에서 비어있는 영역 후보:

1. **"활성형 B12 (메코발라민)" 카테고리 선점** — 일동·대웅 모두 미점유, 벤포벨S만 보유
2. **"신경 피로 / 손발저림 / 말초신경"** 메시지 — 아로나민 일부 라인 외 약함, 메코발라민 클레임으로 차별화 가능
3. **"어른" 정체성의 확장** — 30~40대 직장인 + 50대 시니어 다리 놓기 (현재 약사 평가는 40대 45% 중심)
4. **"약사 추천 인식의 가시화"** — 약사 1,000명+ 권매 포인트 데이터를 (직접 광고는 안 되지만) 약국 POP·디지털 콘텐츠로 활용

## 6. 광고기획서에 반영할 결정 포인트

### 6.1 모델 전략

- **이성민 4년차 유지** vs 신규 모델 발탁
- 유지 권장 사유: 슬로건 무결성·신뢰도 자산 누적
- 변경 검토 사유: 30~40대 디지털 타겟 확장 시 추가 모델 (서브 모델 운영 검토)

### 6.2 메시지 진화 방향

- **(α) "어른들의 비타민" 우산 유지** + 서브 메시지로 활성형 B12·메코발라민 강조
- **(β) "신경 피로" 카테고리 신설** — 아로나민 미점유 영역 선점
- **(γ) 약사 추천 시각화** — 약국 POP 중심, 광고에서는 간접 표현
- 권장: **α + γ 조합** + β는 후속 캠페인에서 검토

### 6.3 채널 전략

- TV CF 메인 + 디지털 (유튜브 짧은 영상, 인스타) + 약국 POP
- 디지털에서는 30~40대 타겟 메시지 별도 운영 권장

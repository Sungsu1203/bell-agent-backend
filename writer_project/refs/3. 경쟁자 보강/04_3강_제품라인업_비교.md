### 2.2 핵심 차별화

- **푸르설티아민의 뇌세포막 통과 클레임** — "마늘주사" 주성분과 동일하다는 점을 마케팅 전면에 활용
- 일동제약은 "활성형 비타민 B1" 개념 자체를 시장에 정착시키고 자기 브랜드로 연결시킨 사례 (히트뉴스 2026 약사 분석)
- 한국능률협회 브랜드파워 11년 연속 1위

### 2.3 라인업 운영 전략

- **수직 라인업** (베이스 → 프리미엄)으로 가격대·함량 단계화
- **수평 라인업** (씨플러스/이맥스/실버/아이)으로 효능별 세분화
- 약사 추천 워크플로우: 일반 → 활성형 → 작용부위별 (벤포티아민 vs 푸르설티아민 안내) → 제품 선택

### 4.3 핵심 차별화

#### A. 활성형 B1 "최적의 밸런스"

- 벤포티아민 100mg (생체이용률 ↑) **+** 비스벤티아민 30mg (장관흡수성 ↑, BBB 통과 → 정신적 피로 개선)
- 단일 성분 우열 비교(2.4 광고규제 자료 참조)에서 벗어나 "조합" 차원으로 이동

#### B. 국내 최초 OTC 메코발라민 함유

- 메코발라민은 기존 **전문의약품**으로 처방되던 말초신경병증 치료 성분
- 시아노코발라민(비활성형) 대비 체내 약 2.5배 강력 작용, 소변 배설량 약 1/3 → 조직 잔류↑
- B12 드럭머거인 **메트포르민**(당뇨)·**PPI**(위장약) 장기 복용자, 시니어 추천 가능

#### C. UDCA 60mg — 표준제조기준 최대치

- 비타민 복합제 일반 25~30mg → **2배 함량**
- 메티오닌·타우린·오로트산과 시너지 → 간 해독·항산화

#### D. 만 19세 이상 성인 한정 → "어른들의 비타민" 슬로건 일관성

- UDCA 60mg 함량 때문에 용법상 성인 한정
- 슬로건과 처방 사양이 일치 → 메시지 무결성 높음

### 4.4 약사 평가 (2023.02~03 약사공론 설문, 약사 1,000명+)

- 벤포벨S 주요 타겟층 — **남성 89%**, 여성 11%
- 연령별 — 40대 45%, 30대 23%, 50대 19%
- 가장 좋은 권매 포인트:
  - **UDCA + 타우린 + 메티오닌 + 오로트산 조합**: 56%
  - 벤포티아민 100mg + 비스벤티아민 30mg: 22%
  - 활성형 B12 메코발라민: 16%

> 약사 인식: **간기능 + 종합 처방 조합**이 차별화의 1순위로 평가됨. 단일 성분 클레임보다 "조합 가치"가 약국 추천 동력.

## 5. 광고기획 시사점 — 라인업 관점

### 5.1 라인업 폭에서는 아로나민이 압도적

- 7+ 라인업 vs 임팩타민 5 vs 벤포벨 3
- 약사가 환자 상태별 추천할 때 "맞춤 옵션"이 풍부 — 약국 채널에서 강력
- **벤포벨이 라인업 폭으로 정면 경쟁하면 불리.** "S정 단독 임팩트"로 승부하는 현재 전략이 합리적.

### 5.2 처방 통합도(integration)에서는 벤포벨S가 우위

- 벤포벨S = 활성형 B1(2종) + 활성형 B12 + 간기능 60mg + 신경피로 + 근육피로를 **단일 정제**에 통합
- 아로나민·임팩타민은 각 효능을 **별도 라인업**으로 분산 (씨플러스=항산화, 이맥스=혈액순환, 실버=중장년 등)
- **벤포벨 메시지: "한 알로 어른의 모든 피로"** — 라인업 폭의 단점을 통합 처방으로 역전

### 5.3 약사 인식 자산 — 벤포벨의 진짜 힘

- 약사 1,000명+ 설문에서 **"UDCA+타우린+메티오닌+오로트산 조합"이 권매 포인트 1위 (56%)**
- 즉 **약사는 벤포벨S를 단순 비타민이 아닌 "간 해독·신경 통합 처방"으로 인식**
- 이 인식을 소비자 광고에서 그대로 가져갈지, 별도 약사 매체에 한정할지 결정 필요
  - 소비자에게 "간기능"을 강조하면 OTC 광고 규제(2.1 자료 참조) 회피 어려움
  - 광고는 "어른들의 피로" 우산 메시지로, 약사 매체는 "간기능 + 신경통" 디테일로 분리 권장

### 5.4 모델·메시지 일관성에서 벤포벨의 자산

- 이성민 3년+ 연속 모델 → 신뢰도·인지도 누적
- "어른들의 비타민" 슬로건과 처방 사양(만 19세 한정) 일치 → 메시지 무결성
- 아로나민도 "먹은 날과 안 먹은 날의 차이" 일관성 유지 중 (10년+) — **장기 슬로건 자산이 양강 구도, 임팩타민은 슬로건 일관성 약함**

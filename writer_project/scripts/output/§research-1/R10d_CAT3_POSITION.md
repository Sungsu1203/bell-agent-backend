## 1. 🔴 self-check #45 — 노드 동일성 판정 방식 (이번 차수 핵심)

### 1-a. 무엇으로 판정했나 = **`nodes[u]` 인덱스**

**텍스트 비교가 아니다.** 다음 2단으로 잠갔다.

**① 출처 노드 인덱스 보관** — `select_body_nodes()` 가 `(idx, text, chain)` 을 돌려주고, `extract_probe_phrases()` 가 어구마다 `src_idx` 를 함께 반환한다.

**② 히트 노드 인덱스 산출 + 개수 assert**
```python
idxs = [i for i, (t, _n) in enumerate(nodes[u]) if key_ph in t] if len(key_ph) >= P.MIN_SPAN else []
assert len(idxs) == len(hits)          # find_chains 술어와 동일 · 원순서 1:1
```

**③ 🔴 인덱스 동일 ⟺ 객체 동일 을 매 히트 검증**
```python
same = (i == src_idx)
assert same == (nodes[u][i][1] is nodes[u][src_idx][1])
```
`is` = **파이썬 객체 동일성**. 전 히트 965건에서 assert 위반 0.

→ **인덱스 판정과 객체 판정이 전건 일치한다.** 텍스트 일치에 의존한 부분은 없다.

### 6-c. 🔴 deviation ③ 출처 명시 (self-check #49)

**질문** — "복원에 실패했는데 `R10c §9` 의 '변경 전 전문' 은 어디서 왔나."

**답 = 실패한 복원본이 아니다.** 출처는 **각 편집의 `old_string` 원문**이다.

| 항목 | 내용 |
|---|---|
| 출처 | 편집 도구에 넘긴 `old_string` 값 |
| 검증 강도 | **byte 일치가 보장된다.** 치환은 `old_string` 이 그 시점 파일에 **정확히 1회 존재**할 때만 성공한다. 성공했다는 사실 자체가 해당 블록이 수정 전 파일에 byte 단위로 존재했음의 증거다 |
| 한계 1 | **변경 지점만**이다. 파일 전체 diff 가 아니며, 편집이 닿지 않은 영역은 대조되지 않았다 |
| 한계 2 | 각 블록의 **파일 내 위치·순서**는 편집 기록이 아니라 서술로 재구성했다 |
| 폐기물 | 역산 복원본(`df7192…`)은 목표 `780bec…` 와 불일치 → **폐기했고 어디에도 싣지 않았다** |

**재발 방지 적용** — 이번 차수는 수정 전 원본 사본 2부를 먼저 떴다(§0-a). `e17fab…` 대조 완료.
⚠️ 지시 §6-c 가 확인한 대로 **`probe_s2_agg.py` 는 sha256 불변이므로 R9 비교 근거는 흔들리지 않으며**, #36 의 증거도 diff 가 아니라 *"리팩터 후 본선 값 완전 동일(922/1240)"* 이라는 행동 증거다.
